# Appointment Booking System

## Overview
This project is a web-based Appointment Booking System developed using Django. It allows patients to book, update, and cancel appointments with doctors.

## Features
- Patient registration and login
- Book appointment
- Update appointment
- Cancel appointment
- Patient dashboard

## Technologies Used
- Python
- Django
- HTML, CSS
- SQLite

## Project Structure
- clinic_project/ → Main Django project
- core/ → Application logic (models, views, forms)
- templates/ → HTML templates

## How to Run
1. Clone the repository
2. Navigate to project folder:
   cd clinic_project
3. Run migrations:
   python manage.py migrate
4. Start server:
   python manage.py runserver
